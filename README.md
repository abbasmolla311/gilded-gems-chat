# Gilded Gems Hub

Build a luxury Jewellery Store and WhatsApp Commerce web app with ivory/gold premium aesthetic. Features: product catalog (Gold, Silver, Diamond, Bridal collections) with purity, weight, and making charges; direct 'Order on WhatsApp' with formatted product details; multi-item cart with bulk WhatsApp order checkout; and an Admin/Stock Management dashboard to manage products, pricing, categories, and inventory.

This project was built with [Lovable](https://lovable.dev).
